# Kirbet

Telegram-бот (@kirbet_bot) для мониторинга коэффициентов казахстанских букмекеров, сопоставления одинаковых
событий и поиска арбитражных ситуаций («вилок»). Это аналитический сервис: **ставки он не размещает и прибыль
не гарантирует**.

Стек: Python 3.12, asyncio, Zendriver (Chrome), BeautifulSoup + lxml, Pydantic, SQLAlchemy 2 + Alembic,
PostgreSQL, aiogram 3. Сервер: boxd `telegrambot` (Франкфурт, 8 ГБ RAM), служба systemd `arb-bot`.

Документация по эксплуатации, подпискам, платежам и CLI — [docs/OPERATIONS.md](docs/OPERATIONS.md).
Черновики документов для пользователей (требуют проверки юристом): [соглашение](docs/terms.md),
[риски](docs/risks.md), [конфиденциальность](docs/privacy.md).

## 1. Текущее состояние (19.11.2026, проверено на сервере)

### Букмекеры Казахстана (реестр ЕСУ, cmaai.kz — ровно эти 8 брендов)

| Букмекер | Статус | Событий | Рынков | Как получаем данные | Ограничение |
|---|---|---:|---:|---|---|
| OLIMPBET | ✅ WORKING | ~307 | ~594 | Zendriver: главная («Топ события», клики по вкладкам) + страницы турниров `/line/<вид>/<турнир>` | читаются приоритетные и крупнейшие турниры, не все |
| FONBET | ✅ WORKING | ~85–92 | ~230–250 | Zendriver: 8 страниц `/sports/<вид>` | из Германии сайт отдаёт английскую версию; обновление раз в 10 мин (чаще — 403) |
| WINLINE | ✅ WORKING | ~70–110 | ~170–230 | Zendriver: «Линия» `/sport/all` + главная | часть рынков (теннис #187/#203 и др.) не опознана и в вилках не участвует |
| UBET | ✅ WORKING | 130 | 130 | Zendriver: главная, JSON, который загрузила сама страница | только футбол 1X2 (топ-линия) |
| 1XBET | ⛔ BLOCKED | 0 | 0 | — | JS страницы перенаправляет на `/ru/block` (геоблокировка) |
| PARIMATCH | ⛔ BLOCKED | 0 | 0 | — | HTTP 403 по IP сразу, даже на `robots.txt` |
| OINABET | ⛔ BLOCKED | 0 | 0 | — | Cloudflare, HTTP 403 |
| TENNISI | ⚫ UNAVAILABLE | 0 | 0 | — | TCP-соединение с сервера не устанавливается; с IP Казахстана — запрет robots.txt (`Disallow: *?*`) |

Заблокированные источники **не обходятся**: нет ротации IP, прокси, обхода CAPTCHA/Cloudflare и подмены
заголовков. После блокировки адаптер ждёт 30 минут и пробует снова одной загрузкой. Чтобы получить
1XBET/PARIMATCH/OINABET/TENNISI, нужен сервер с IP в Казахстане или официальный B2B-фид оператора.

Другие источники: Polymarket, Kalshi (работают), The Odds API (работает, ~400 кредитов в месяц, дневной
лимит), Betfair (нет ключей).

### Последние измерения на сервере

* 10 циклов сканирования подряд: 0 ошибок, 0 перезапусков; 2315–2340 рынков за цикл; средний скан ≈ 58 с;
  сопоставление < 1 с; бот ≈ 485–500 МБ RAM, CPU ≈ 5 %; сервер 38–46 % RAM.
* Сопоставлено 188–194 группы событий, из них 58–61 — у 2+ казахстанских букмекеров; отсеяно ~90 ложных
  совпадений за цикл (в основном «совпал только один участник»).
* Кандидатов на вилку 5–12 за цикл, **ни один не прошёл повторную проверку** (разные правила расчёта,
  устаревшие цены, недоступная ставка). Подтверждённых вилок за эти циклы нет.
* Суточный тест стабильности запущен 19.11 16:50 UTC (`scripts/stability_monitor.sh`, лог `~/stability/` на
  сервере, запись каждые 15 минут) — результат ещё не получен.
* Тесты: 163 пройдено (`pytest -m "not live"`), ruff без замечаний.

## 2. Что работает

* **Сбор данных** — один Chrome (Zendriver) на процесс, вкладка на страницу, проверка robots.txt (включая
  адрес после редиректа), тайм-ауты, HTTP-статус, распознавание 403/Cloudflare/антибота/страницы блокировки,
  перезапуск Chrome при > 1,5 ГБ или каждые 300 страниц. HTML разбирается в отдельном потоке.
* **Виды спорта**: футбол, теннис, хоккей, баскетбол, волейбол, гандбол, футзал, киберспорт (CS2, Dota 2,
  LoL, Valorant — по названию турнира), MMA, единоборства и др. Кибер-футбол («Наполи (Rodja) — Рома (Bjela)»)
  отделён от настоящего футбола.
* **Рынки**: 1X2 / победитель — все виды; фора и тотал — собираются у Fonbet, Olimpbet, Winline;
  двойной шанс — Olimpbet. В поиске вилок: 1X2/победитель и **футбольные фора и тотал только с линией x.5**
  (без возврата ставки), линия — часть ключа рынка.
* **Сопоставление событий** (`app/matching`, `app/normalization`): вид спорта, тип рынка, период, время,
  оба участника; русские и английские названия (транслитерация, фонетические ключи, словарь клубов),
  фамилия/имя в любом порядке; маркеры жен./мол./рез./любители; «Динамо» ≠ «Динамо Минск»; порог уверенности
  0,9; принятые совпадения с уверенностью и причиной сохраняются в `matched_events`.
* **Вилки**: Decimal, комиссии бирж/рынков предсказаний, лимиты, округление, курсы валют; перед уведомлением
  цены загружаются заново и вилка пересчитывается; кандидат не выдаётся за подтверждённую вилку.
* **Время**: везде IANA `Asia/Almaty` через zoneinfo, в БД UTC; браузер проверяет, что страница отрисована
  в Asia/Almaty, иначе время матча помечается `timezone_unknown` и не участвует в сопоставлении.
* **Публичный бот**: лимиты частоты, общий кеш скана 90 с, single-flight (500 одновременных запросов →
  1 скан), ограничение уведомлений, защита от дублей.
* **Подписки**: тарифы FREE/BASIC/PRO/VIP в БД, лимиты по дню Алматы, продление, истечение, напоминания.
* **Платежи**: Telegram Stars, подписка только по подтверждению Telegram, повторный webhook не активирует
  повторно, возврат. **Выключены** (`PAYMENTS_ENABLED=false`) до решения владельца.
* **Админ-панель** в Telegram: просмотр пользователей, подписок, платежей, ошибок, источников, сканов;
  изменения — только после `/auth PIN`; всё пишется в `audit_logs`.
* **Эксплуатация**: PostgreSQL на сервере (только 127.0.0.1), миграции Alembic, удержание данных,
  `python -m app.cli status | health | stats | bookmakers | scan`, уведомления админу о сбоях,
  снимки машины и `pg_dump` для отката.

## 3. Что не работает или ограничено

1. 1XBET, PARIMATCH, OINABET, TENNISI — недоступны с сервера во Франкфурте (см. таблицу).
2. Live-события собираются, но **в вилках не участвуют**: источники обновляются раз в 5–15 минут, для live
   этого мало, а чаще нагружать сайты нельзя (Fonbet уже отвечал 403).
3. Фора/тотал в вилках — только футбол и только линии x.5. На момент записи совпадающих футбольных линий между
   букмекерами ещё не найдено: Fonbet показывает в основном РПЛ, Olimpbet читал другие турниры. Выбор турниров
   Olimpbet исправлен (РПЛ, Казахстан, еврокубки — первыми), эффект проверяется.
4. OLIMPBET читает не все турниры (≈20 страниц за проход, обновление раз в 15 минут).
5. Winline: часть рынков не опознана — помечены номером и не сопоставляются.
6. Ubet — только футбол 1X2.
7. Подтверждённых вилок в последних проверках нет. Это ожидаемо: крупные КЗ-букмекеры близки по ценам.
8. Суточный тест стабильности ещё идёт.
9. Платёж в тенге (Kaspi и др.) не реализован — нужен договор с банком/эквайером.
10. Юридические вопросы не закрыты: закон РК о персональных данных требует хранить данные граждан РК в
    Казахстане (сервер в Германии); Ubet, Parimatch, Winline считают игру на вилках недобросовестной;
    коммерческий сервис вокруг ставок требует проверки юристом.

## 4. Журнал работ: что делалось и какие ошибки исправлены

### Сбор данных
* Переписан сборщик на Python 3.12 + Zendriver (вместо Playwright): единый `ZendriverClient`, адаптеры
  `app/providers/bookmakers/<букмекер>/` (provider, parser, normalizer, models, tests).
* Ubet переведён с Playwright на Zendriver; Playwright остался только для старых исследовательских скриптов.
* **Ошибка Ubet**: время матчей сдвигалось на 5 часов (UTC читалось как время Алматы). Сверено с Fonbet,
  исправлено.
* **Ошибка Fonbet**: с сервера приходило 2 события вместо ~50 — сайт отдаёт английскую версию, парсер ждал
  русские заголовки колонок. Парсер теперь понимает оба языка (повторные «1»/«2» = фора).
* Fonbet расширен с 4 до 8 видов спорта; несуществующие разделы, которые сайт подменяет футболом, отсекаются.
* Fonbet отвечал 403 при частом обновлении → после первого 403 остальные страницы не открываются, обновление
  раз в 10 минут.
* Winline: с главной (62 события, 1 рынок) на «Линию» `/sport/all` (до ~110 событий, фора/тотал).
* **Ошибка Winline**: кибер-футбол помечался как футбол → отдельный вид спорта для кибер-версий.
* **Ошибка классификации**: американский футбол считался футболом → исправлено.
* Olimpbet: «Топ события» с кликами по вкладкам + страницы турниров (1X2, двойной шанс, фора, тотал).
* **Ошибка производительности Olimpbet**: разбор одной страницы занимал 7,2 с (квадратичный поиск по
  документу) и блокировал бота на ~40 с за скан — отсюда задержка запуска Telegram polling до 90 с.
  Парсер стал линейным (0,34 с), разбор вынесен в поток. После исправления polling стартует за 2 с.
* 1xBet/Oinabet: сначала проверяется публичная страница; при блокировке API не вызывается.
  **Ошибка**: блок 1xBet не распознавался (редирект на `/ru/block` из JS через пару секунд) — исправлено.
* Parimatch: при 403 перебирались все 4 страницы каждые 5 минут → остановка после первого 403 и пауза 30 мин.
* Tennisi: тайм-аут повторял загрузку → без повтора; диагностика DNS/TCP/TLS показала, что TCP не
  устанавливается.
* Ubet: снимки коэффициентов не сохранялись в БД → сохраняются.

### Сопоставление и вилки
* Русские ↔ английские названия: «Ben Shelton» = «Шелтон Бен», «Rafael Jodar» = «Ходар Рафаэль»,
  «Akron Tolyatti» = «Акрон», «Dynamo Moscow» = «Динамо Москва»; словарь из 20+ клубов (Бавария ↔ Bayern).
* **Ошибка**: «Andy Murray» совпадал с «Andy Murphy» (совпало имя) → оба имени обязаны совпасть.
* **Ошибка**: «Hertha Berlin» ≈ «Герта Берлин (люб)» — маркеры состава терялись при транслитерации → исправлено.
* «Dinamo» больше не поглощает «Dinamo Minsk» (защита общих названий клубов).
* Порог уверенности поднят с 0,85 до 0,9; счётчик отсеянных совпадений по причинам.
* Проверка на живых данных: 37 групп с Fonbet просмотрены — ложных совпадений нет.
* Фора и тотал добавлены в поиск вилок (футбол, линии x.5, одинаковая линия).

### Время
* Везде `Asia/Almaty` через zoneinfo, без ручных «+5»; БД — UTC; логи — UTC и Алматы.
* **Ошибки**: бот показывал время в зоне сервера; Kalshi переводил зоны вручную с запасным «-5»;
  Oinabet/Polymarket/Kalshi молча считали время без зоны UTC — исправлено (неизвестная зона не угадывается).
* Плановый скан идёт по сетке часов Алматы; дневные лимиты и бюджет The Odds API сбрасываются в полночь Алматы.

### Публичный бот, подписки, платежи, админка
* Бот открыт для всех; лимиты частоты, кеш 90 с, single-flight, лимит уведомлений, `/status`.
* **Ошибка**: после неудачного скана могли показываться старые данные как свежие → честное сообщение
  с временем последнего успешного обновления.
* Тарифы, подписки, Telegram Stars (выкл.), админ-панель с PIN, аудит, юридические черновики.
* The Odds API: дневной лимит кредитов, учёт каждого платного ответа, предупреждение при остатке < 100.

### Инфраструктура
* PostgreSQL на сервере; данные перенесены из SQLite и сверены построчно; SQLite-копия сохранена.
* **Ошибка деплоя**: скрипт перезаписывал на сервере `.env` и базу пользователей → `.env` и БД на сервере
  больше не перезаписываются.
* **Ошибка деплоя**: использовался tar из Git Bash вместо Windows tar → исправлено.
* Снимки машины для отката: `before-final-task`, `before-commercial`, `before-handover-work`; дамп БД в
  `~/backup/`.

### Исследования
* Готовые парсеры (r-1805/vilki, pvolnov/Fonbet-1xBet-parser, Habeel-Shamsudeen/sportsbook-scraper,
  myselfshravan/pariScrapper, ScorpLanding/bkbot): без лицензий, не под домены .kz, часть использует
  ротацию IP/подмену заголовков — код не использован.
* proxy-tools.com: API только с платным Pro Status, условия запрещают scraping, 412 из 414 KZ-прокси
  прозрачные — не подключён. Модуль `app/proxy_manager/` выключен и никогда не используется для обхода
  блокировок, Telegram или API-ключей.
* PIN-UP: отсутствует в реестре ЕСУ, по владельцам ведётся дело АФМ — не включён.

```
  providers/browser/zendriver_client.py   единый браузер (robots, тайм-ауты, статусы, watchdog)

  arbitrage/ validation/                  расчёт и повторная проверка вилок (Decimal)
  billing/                                тарифы, лимиты, подписки, платежи
  telegram/bot.py, telegram/commerce.py   бот, команды, оплата, админ-панель
  scheduler/ main.py                      плановый скан, кеш, уведомления, ежедневные задачи

  ops.py                                  CLI status / health / stats

deploy/                                   деплой на boxd, systemd, PostgreSQL
scripts/                                  диагностика, миграция SQLite→PostgreSQL, мониторинг стабильности
```

## 6. Запуск

```bash
uv venv .venv312 --python 3.12 && uv pip install --python .venv312 -r requirements-dev.txt
cp .env.example .env            # заполнить TELEGRAM_BOT_TOKEN и др.
.venv312/bin/alembic upgrade head
.venv312/bin/python -m app.cli bot           # бот + сканер
.venv312/bin/python -m app.cli health        # проверка
.venv312/bin/python -m pytest -m "not live"  # тесты
```

Деплой на сервер: `powershell -ExecutionPolicy Bypass -File deploy\deploy_boxd.ps1 -Machine telegrambot -Region fra`.
Секреты хранятся только в `.env` на сервере (в репозитории их нет; образец — `.env.example`).
